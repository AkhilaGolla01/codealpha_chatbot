# Basic Chatbot

## Description
A simple rule-based chatbot created using Python.

## Features
- Responds to greetings
- Responds to "how are you"
- Says goodbye when the user types "bye"
- Handles unknown messages

## Technologies Used
- Python
- If-else statements
- While loop
- User input

## How to Run
Run the `chatbot.py` file using Python.

## Example
You: hello
Bot: Hi!

You: how are you
Bot: I'm fine, thanks!

You: bye
Bot: Goodbye!
